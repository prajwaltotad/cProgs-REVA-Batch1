## 📌 About the Repository

Welcome to **cProgs-REVA-Batch1**!

This repository serves as my programming practice space for learning C, strengthening problem-solving skills, and understanding the fundamentals of computer science through hands-on coding.

From basic syntax and control flow to arrays, pointers, and dynamic memory allocation, the goal is to build a strong foundation by writing, testing, debugging, and improving C programs.

### 🎯 Objectives

- 🧠 Strengthen logical thinking and computational problem-solving.
- 💻 Practice C programming concepts through hands-on implementation.
- 🔍 Understand how algorithms translate into executable programs.
- 🛠️ Improve debugging skills and write cleaner, more readable code.
- 📈 Build a consistent coding habit and track my learning progress.

## 🚀 Getting Started

Want to explore or run the programs locally? Follow these steps.

### 1. Clone the repository

Open your terminal and run:

```bash
git clone https://github.com/prajwaltotad/cProgs-REVA-Batch1.git
```

### 2. Navigate to the project directory

```bash
cd cProgs-REVA-Batch1
```

### 3. Open in VS Code

```bash
code .
```

### 4. Compile a C program

Make sure GCC is installed and available in your system's PATH.

```bash
gcc program.c -o program
```

Replace `program.c` with the name of the C source file you want to compile.

### 5. Run the program

**Windows PowerShell:**

```powershell
.\program.exe
```

**Linux / macOS:**

```bash
./program
```

> 💡 **Tip:** Compile and run each program individually, especially when different files contain their own `main()` function.

## 🧑‍💻 My Approach to Learning

I believe the best way to learn programming is to write code, understand why it works, and improve it through practice.

My approach is to:

1. Understand the problem before writing code.
2. Break the problem into smaller steps.
3. Implement a solution using the appropriate C concepts.
4. Test the program with different inputs and edge cases.
5. Debug errors and improve the solution whenever possible.
